# Four Card Feature Section

A responsive feature section component built as part of a Frontend Mentor challenge.

## Overview

### The Challenge
Users should be able to view the optimal layout for the site depending on their device's screen size (Mobile & Desktop).

- CSS Grid & Flexbox
- Mobile-first workflow

- Structuring components using clean, semantic HTML tags.
- Applying BEM naming conventions for organized and maintainable CSS.
- Styling distinct feature cards with visual top borders and clean shadows.
